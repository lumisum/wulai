# 无来公众号配图

为“无来”的文章制作一组安静、清晰、当代的公众号图片。画面从文章真实表达出发，以视觉承接作者的个人修学体会；不把个人理解画成普遍教义，不替文章添加经文、说法或结论。

## 开始前

1. 阅读项目的[配图风格指南](../../../guides/image-style.md)，并遵循其中的既定风格与比例；同时以项目 README 头图 `../../../assets/wulai-readme-hero.png` 作为固定品牌配色参考。
2. 阅读文章正文、标题和公众号摘要，明确文章真正讨论的问题、读者应带走的体会，以及配图在正文中的位置。正文尚未完成时，只使用用户给定的主题与素材，不臆造文章内容。
3. 判断用户要的是画面构思/提示词，还是实际图片。明确要求提示词时只交付提示词；要求图片或配图时，使用当前环境的内置 `image_gen` 工具生成实际图像。多张不同画面要分别准备提示词并分别生成，不能用同一个提示词批量代替不同构图。

## 规格与文件

- **封面：**横版 `2.35:1`，目标尺寸 `1880 × 800 px` 或更高的同等比例，保存为 `images/cover.png`。
- **正文插图：**竖版 `3:4`，目标尺寸 `1200 × 1600 px` 或更高的同等比例，通常每篇约三张，保存为 `images/01.png`、`images/02.png`、`images/03.png`。数量和位置服从文章节奏，不机械地每章一图，也不为凑数重复画面。
- 图片放在对应文章目录的 `images/` 中。若文章目录尚不存在，按项目约定建立必要目录，不擅自改写文章正文或其他文章索引。
- 生成后检查每张图的主题、构图、画幅和文件。不得拉伸变形；若输出比例与目标不符，先用保持内容完整的方式修正画布，再确认主体与重要细节没有被裁掉。
- 不覆盖已有图片，除非用户明确要求替换。否则为新版本使用 `cover-v2.png`、`01-v2.png` 等文件名，并在交付时说明。

## “无来”的视觉语言

核心气质是**清、静、温、当代**：有观照和内在宁静的感觉，但不套用陈旧的宗教海报视觉。佛法意境更多来自对日常、变化、关系和因缘的细看，而不是堆叠宗教符号。

优先从文章自身寻找画面：自然光、风、水纹、山的远近层次、石、树影、窗、纸、器物、人与空间的距离、手部动作，以及真实生活里短暂而具体的时刻。用柔和但有方向的光线、克制的景深、自然材质和有意图的留白营造安定感。

### 固定品牌配色

所有文章封面和正文配图都使用与 README 头图 `../../../assets/wulai-readme-hero.png` 一致的青松绿配色组合。头图是视觉基准；每次构思提示词前先对照它，整组图片维持同一冷暖关系，不因单篇文章随意换成另一套色系。

- **主色与阴影：**深青松绿、绿黑、低饱和松针绿，例如 `#172018`、`#212A22`；用于林木、室内阴影、远山和画面深处。
- **中间色：**克制的苔绿、灰绿和石色，例如 `#363726`；用于植被、山石与自然过渡层次。
- **暖光与点缀：**温润象牙米、日出香槟色和旧铜暖褐，例如 `#EED8BC`、`#FAE1BA`、`#AB8966`；用于自然光、墙面、木石受光面与少量细节。
- 色值是取自头图的近似参考，不要求逐像素匹配；每张图都要保留“青松绿/绿黑的沉静底色 + 象牙米与淡金色的温暖受光 + 少量灰绿石色”的整体组合。可以根据场景调整明暗和各色面积，但封面与正文图必须共享这套色相和质感。
- 避免鲜艳蓝、青紫、正红、荧光绿、亮橙或大面积纯金色，也不要为了营造佛意改成统一的金色滤镜。画面可以明亮或幽暗，色彩仍回到头图的青松绿与暖象牙光。

避免把“佛系”简化为佛像、莲花、香炉、寺庙飞檐、僧人剪影、经卷与金色光芒的组合。文章内容确实涉及某一符号或仪式时，可以谨慎呈现，但要保持准确、克制和尊重。不要生成伪经文、乱码书法、伪造佛教文字、宗教标语、平台标志、二维码或水印。

## 封面与正文图的分工

### 封面（2.35:1）

- 从文章的核心体会中提炼一个可见画面：一个清楚的主体、一处具体情境或动作、一层能引起读者共鸣的关系。不能只画抽象哲理，也不必把正文所有观点塞进一张图。
- 用横向空间安排主体、环境和留白，缩小到公众号列表预览时仍看得出画面重点。封面与文章标题表达同一主题，但默认**不在生成图中写标题或任何文字**；为后期排版保留自然、干净的留白。
- 让封面在色调、光线、材质上引出正文配图，同时使用更简洁、更有记忆点的构图。不要把竖图横向拉伸或只做机械裁切。

### 正文插图（3:4）

- 先通读文章，再挑约三处真正需要视觉停顿的位置。每张图分别服务于一个具体段落或体会，可从“生活处境—觉察与理解—回到日常的行动”发展，但仅当文章内容确实支持这条变化时才采用。
- 每张图都能独立理解，同时共享一套克制的视觉气质。避免三张图重复同一个山水、莲花或人物背影；让场景、视点或主体动作各自承担不同作用。
- 充分使用竖向画幅组织前景、中景和背景，建立自然的视线流向。主体足够清晰，不让关键动作、表情或文章相关物件缩得过小。
- 画面可以具体、含蓄，不必每张都出现人物。出现人物时，以正文中的人物关系和处境为准，不预设年龄、性别、身份或情绪。

## 编写图片提示词

每张图使用独立、可直接交给图片模型的提示词。提示词要包含与该图有关的文章标题或主题、画面承担的作用、主体和动作、场景、构图与视点、光线、固定品牌配色、材质、情绪，以及准确的画幅比例。明确写出“与无来 README 头图一致的深青松绿/绿黑、灰苔绿石色、暖象牙与淡香槟日光、少量旧铜色”，不可只笼统写“佛系配色”或“自然色调”。细节应服务于文章含义，不堆砌无关物件、抽象节点和装饰性光效。

默认要求：画面无文字、无字母、无水印、无边框；不要伪经文、乱码、符号拼贴、空洞背景、重复主体或夸张宗教海报感。若用户明确要求图中文字，先把准确文字和排版方案单独列出；不要把长段中文交给图片模型直接渲染，除非用户明确接受其文字生成限制。

实际生成图片时，遵循当前环境的图像生成工具说明。生成后逐张检查：是否忠实于文章、是否符合“无来”的视觉语言、主体是否明确、尺寸比例是否正确，以及是否意外出现文字或不准确的宗教符号。只针对发现的问题做小幅定向迭代，并保留已存在的原图。

## 交付

- 把最终图片保存到对应文章的 `images/` 目录，并报告封面与每张正文图的文件路径。
- 简要说明每张图对应的文章位置或视觉作用；如果只产出了提示词，明确标记为提示词而非已生成图片。
- 更新文章索引、发布状态或文章内容仅在用户另有要求时进行。
