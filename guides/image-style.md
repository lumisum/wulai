# 配图风格指南

## 图片规格

- **公众号封面：**横向比例 `2.35:1`，建议输出 `1880 × 800 px` 或更高的同等比例尺寸，文件名为 `cover.png`。
- **正文插图：**统一使用纵向比例 `3:4`，建议输出 `1200 × 1600 px` 或更高的同等比例尺寸，文件名依次为 `01.png`、`02.png`、`03.png`。
- 每篇文章通常准备一张封面和约三张正文图；以文章节奏为准，不为凑数量而重复表达。
- 图片中不直接生成标题、标语、经文或水印。需要文字时，在公众号编辑器中另行排版。

## 视觉方向

整体安静、清透、有留白，能让人联想到观照、慈悲、因缘、无常等佛法意境，但保持当代、克制的视觉表达。可从自然光、山水的远近层次、风、水纹、石、树影、窗景、纸面肌理和简练的抽象形态中取材。

### 固定品牌配色

所有文章封面与正文插图统一参考项目 README 头图 [`assets/wulai-readme-hero.png`](../assets/wulai-readme-hero.png)。每张图都保留头图的整体色彩关系：青松绿与绿黑构成沉静底色，灰苔绿和石色做中间过渡，暖象牙米与淡香槟日光提供温度，少量旧铜暖褐用于自然材质和细节。

- **深青松绿 / 绿黑：**约 `#172018`、`#212A22`，用于阴影、远景、树木和画面深处。
- **灰苔绿 / 石色：**约 `#363726`，用于植被、山石和中间层次。
- **暖象牙 / 淡香槟光 / 旧铜：**约 `#EED8BC`、`#FAE1BA`、`#AB8966`，用于日光、受光面和少量暖色细节。
- 色值来自头图取样，作为近似参考而非逐像素要求。可以按场景调整明暗与面积，但所有图片保持同一组青松绿、暖象牙光和低饱和自然中间色；不要让不同图片各自偏向蓝、紫、红、荧光绿、亮橙或大面积金色。

头图是所有配图提示词的配色锚点。封面与正文图即使画面题材、时间和光线不同，也要看起来属于同一个视觉系列；以色彩比例和冷暖关系保持一致，不要只在提示词里笼统写“佛系配色”或“自然色调”。

避免把“佛系”简化成固定符号：不要每篇都用佛像、莲花、香炉、寺庙飞檐或僧人剪影，也避免堆叠符号、浓重古风滤镜和廉价宗教海报感。只有当这些元素确实服务于文章内容时，才考虑使用。

## 单篇配图

三张正文图尽量承担不同作用，例如：引出情境、呈现思考过程、落到生活中的观照。封面提炼文章的核心意境，构图简洁，在小尺寸预览时仍有清晰主体。封面与正文图保持色调、材质和光线的一致性，但不必重复同一画面。

## 生成提示词模板

将方括号内容替换为该篇文章的主题与画面设定。每张图单独生成，分别写明画幅比例。

```text
围绕文章《[标题]》的核心体会“[一句话主题]”创作一张微信公众号[封面 / 正文配图]。
画面内容：[具体场景、主体和构图]。视觉表达安静、清透、当代、克制，具有观照与内在宁静的气息；沿用 README 头图配色：深青松绿/绿黑的沉静底色、灰苔绿与石色过渡、暖象牙米和淡香槟色自然受光、少量旧铜暖褐；使用[光线、材质]，保留充足留白，细节自然，不做说教式表达。
避免陈词滥调和符号堆叠，不要文字、字母、标语、经文、水印或边框。
画幅比例：[封面 2.35:1 横向 / 正文图 3:4 纵向]。
```
