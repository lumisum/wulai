## 关于无来

这里记录我修行、学习佛法的过程，也记录佛法如何回到真实的日常。

我相信，修学不只是寻找现成的答案，也是在每一次观照、选择与实践中，慢慢看清自己的心。文章从个人经历与理解出发，尽量以真诚、平实的文字分享体会；所写是持续学习中的阶段记录，愿与有缘人一起思考、一起前行。
